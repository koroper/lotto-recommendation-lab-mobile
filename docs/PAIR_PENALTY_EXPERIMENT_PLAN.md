# Phase 3 Step 2 — 단일 변수 조합 중복 페널티 실험 사전 계획

이 문서는 실제 데이터 대조 실험을 **실행하기 전에** 고정한 설계이다.
이후 결과에 유리하게 페널티/구간/기준을 바꾸지 않는다.

## 목표와 고정 변수

실제 구매하는 5게임 중 한 게임이라도 3개 또는 4개 이상 맞힌 경험적 빈도를 높일 가능성을 검토한다. 다만 공정한 로또에서 모든 단일 6개 조합의 1등 확률은 같다. 모델 점수 또는 역사적 일치는 미래 당첨 확률이 아니다.

**변경은 딱 하나:** 표준(`표준`) 스타일의 조합 목적함수 `repeated_pairs` 페널티 계수
`0.75 -> 1.50`.

다음은 모두 변경 금지: 6개 번호 분석 모델, 동일가중치, 번호 후보 풀, 콤비네이션 원점수, 빔 탐색 폭, 트리플 중복 페널티, 번호당 반복/최우선 숫자 계수, 5게임 수, 스타일, 데이터 입력.

프로덕션 앱은 선택지를 전송하지 않아 완전히 기존 동작을 유지한다. 내부 Python 엔진에 연구용 `experimentPairPenalty` 키를 명시적으로 전달한 경우에만 후보를 생성한다.

## 실제 이력 평가 범위 (사전 고정)

- 첫 번째 과거 재생 구간: **1152~1175회**, 24회.
- 두 번째 시간상 후행 과거 재생 구간: **1200~1223회**, 24회.
- 합계 48회차 × 5게임, 기존/후보 각각 240게임.
- 대상 회차의 **직전 이력만** 엔진에 입력한다. 타깃 추첨 결과와 그 이후 이력은 추천 계산에 사용하지 않는다.
- 현재 로또 1247회까지의 실제 이력은 공개 원본 두 곳에서 정합성 검사 후 사용한다.
- 이전에 이미 분석했던 **1224~1247회는 이 실험의 승인 근거에서 제외한다.**
- 위 두 창은 과거 재생 비교 구간이지, 실제 미래의 미관측 검증 자료가 아니다.

## 비교 지표 및 판정

- 고정 동일 비용: 5게임/회.
- 3개 이상 맞힌 게임을 하나라도 포함하는 회차 수.
- 4개 이상 맞힌 게임을 하나라도 포함하는 회차 수.
- 게임당 평균 번호 일치 개수.
- 회차별 최다 일치 개수 평균.
- 5게임 사이 중복된 번호 **쌍** 수, 실제 변화 회차 수.
- 각 회차를 같은 과거 정보·같은 실제 결과로 평가하는 쌍별 비교.

**다음 단계의 실험 후보로 유지할 최소 조건(사전 기준):**
1. 두 창 합산 3개 이상 일치 회차 수가 기존보다 **최소 2회 증가**한다.
2. 어느 창에서도 4개 이상 일치 회차 수가 감소하지 않는다.
3. 두 창 합산 중복 번호 쌍 수가 기존보다 **최소 15% 감소**한다.
4. 어느 창에서도 게임당 평균 맞힌 번호 수가 기존보다 **0.02를 초과해 악화되지 않는다**.

이 기준을 통과해도 자동으로 모델을 배포하지 않는다. 역사적 성능을 살펴본 시점부터 이 표본은 더 이상 독립적인 미래 홀드아웃이 아니므로 실제 **1248회 이후의 미관측 추첨**을 이용한 별도 사전 등록된 평가가 필요하다. 조건 미달이면 후보 HOLD.

## 안전과 재현성

- 테스트 및 GitHub CI에서 기존 데스크톱/모바일 골든 추천이 **완전히 동일**해야 한다.
- 각 회차 원본은 타깃 추첨 직전까지 `history[:draw-1]`로 제한한다.
- 운영 앱 UI, SQLite, 구매 확인 기록, 추천 ID 규칙, 현행 연구 승격 게이트는 변경하지 않는다.
- 이번 후보는 연구 실행 경로에서만 사용할 수 있다.
- 후보 적용 버튼이나 실제 APK 업데이트를 요구하지 않는다.
- 무상 공개 데이터·무료 GitHub Actions만 사용하며, 개인키/API 키는 다루지 않는다.
