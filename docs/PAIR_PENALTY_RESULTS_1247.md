- **대상:** 표준 5게임 포트폴리오의 반복 번호쌍 페널티만 0.75에서 1.50으로 증가.
- **사전 등록:** [PAIR_PENALTY_EXPERIMENT_PLAN.md](PAIR_PENALTY_EXPERIMENT_PLAN.md)
- **실제 데이터:** 공식 데이터 미러 2개 원본의 **1~1247회 기록 전체 일치** 확인.
- **대조 실행 로그:** https://github.com/koroper/lotto-recommendation-lab-mobile/actions/runs/40286062916
- **코드:** `quality/pair_penalty_experiment.py`
- **평가:** 1152~1175회와 1200~1223회, 총 48회차. 각 회차 직전 이력으로 기존/후보를 **동일 5게임** 생성·비교. 1224~1247회는 이전에 관찰한 구간이므로 이번 승인 근거에서 제외.
- **실제 앱:** 변경하지 않음. 명시적 실험 설정을 사용하지 않으면 기존 표준 추천을 유지.

## 판정: HOLD / 실전 추천 가중치 변경 없음

- 사전 정의한 네 가지 후보 유지 조건 중 **최소 세 가지 미충족**.
- 후보 페널티 1.50은 이번 근거에서 **기존보다 우수하지 않다**.
- 이를 보완하기 위해 같은 검증 이력에서 페널티 값을 반복 변경·최적화하지 않는다.
- 다른 실험을 하려면 별도 사전 가설 및 평가 기간을 고정하고, 가능하면 이후 신규 회차의 사전 등록된 검증을 포함한다.
- 이번 기록은 AI Studio 에뮬레이터의 테스트 데이터나 실제 사용자 확정 구매 성과가 아닌 **과거 이력 시뮬레이션**이다.
- 모든 고정 6/45 조합의 물리적 1등 확률은 동일한 **1/8,145,060**이며, 역사적 지표로 예측력을 확정할 수 없다.
